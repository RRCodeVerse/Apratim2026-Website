# Apratim 2026 – Fest Website Mockup

An Arabian Nights themed interactive festival website demo built with modern vanilla HTML5, CSS3 animations, and lightweight JavaScript.

## Highlights
- **Layered Desert Sky Parallax**: Interactive moon, drifting clouds, palace, camels, and dunes.
- **Cinematic SVG Stroke Draw**: Dynamic SVG text stroke reveal for festival branding.
- **Interactive Events Modal Carousel**: Category-driven clay vase buttons and duotone slide viewer.
- **Parchment Contact Directory**: Department selection with interactive polaroid preview card.
- **Ambient Decorations**: Swinging lanterns with natural flicker and subtle particle drift.
